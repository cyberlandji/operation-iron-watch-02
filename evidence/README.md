# Evidence Handling

This directory is reserved for investigation evidence generated during
Operation Iron Watch 02.

Examples of evidence include:
- Raw log files
- Packet captures (PCAP)
- Screenshots from analysis tools
- Alert outputs and timelines

For security, privacy, and responsible disclosure reasons, raw evidence is
not stored in this public repository.

This repository focuses on documenting architecture, detection logic,
investigation methodology, and learning outcomes rather than exposing
sensitive artifacts.

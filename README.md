# Operation Iron Watch 02

Operation Iron Watch 02 is a self-designed Blue Team / SOC home lab focused on
network visibility, log collection, detection engineering, and incident
response workflows.

The project simulates realistic attack scenarios against a monitored
environment and documents how alerts are generated, analyzed, and investigated
using open-source defensive tools such as Snort, rsyslog, and Wazuh.

This repository is intended as a learning and documentation project and
reflects my ongoing progression toward a SOC Analyst role.

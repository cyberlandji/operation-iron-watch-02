# Lab Prerequisites

HARDWARE REQUIREMENTS:
- Safeguard Host (Linux)
- Raspberry Pi 3B+ (web-arm01)
- Secondary host running Kali VM (redforge-01)

SOFTWARE REQUIREMENTS:
- VirtualBox
- SSH client
- Git
- Internet access (for updates)

ACCESS REQUIREMENTS:
- SSH access to web-arm01
- SSH access to soc-core02
- Administrative privileges on Safeguard Host

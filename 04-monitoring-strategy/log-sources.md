HOST LOG SOURCES:

- /var/log/auth.log
  - SSH authentication attempts
  - Privilege usage
  - Failed and successful logins

- /var/log/syslog
  - System events
  - Service activity
  - Network-related messages

- Process and user activity
  - Session creation
  - Command execution (where available)

APACHE LOG SOURCES:

- access.log
  - HTTP requests
  - Enumeration patterns
  - Abnormal request rates
  - Suspicious user agents

- error.log
  - Misconfigurations
  - Failed requests
  - Application errors
